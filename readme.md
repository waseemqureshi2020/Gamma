## 📖 About The Project

Gamma is a front-end web application that allows users to browse and share photography. The primary goal of this project was to build a fast, mobile-first website utilizing the **Bootstrap** framework to ensure a seamless experience across all devices. 

The project focuses on clean UI design, responsive layouts, and smooth user interactions without relying on heavy JavaScript frameworks.

## ✨ Key Features

*   **Fully Responsive Design:** Built with Bootstrap's grid system, ensuring the gallery and navigation look perfect on smartphones, tablets, and desktops.
*   **Interactive Photo Gallery:** A clean, visually appealing grid layout to display high-quality images.
*   **Modern Navigation:** A responsive Bootstrap navbar that collapses into a hamburger menu on smaller screens.
*   **Custom Styling:** Custom CSS applied over Bootstrap's default classes to give the app a unique, branded look.

## 🛠️ Tech Stack

*   **HTML5:** Semantic structure and accessibility.
*   **CSS3:** Custom styling, transitions, and layout adjustments.
*   **Bootstrap:** Rapid UI development, responsive grid, and pre-built components.
*   **JavaScript:** DOM manipulation and interactive elements.
